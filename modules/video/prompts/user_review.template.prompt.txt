- ข้อมูลใน {{features}} คือ spec จริงของสินค้า ต้องถูกพูดถึงใน Value section

- ห้ามใช้คำ genéric อย่างเดียว ต้องมี spec ที่เฉพาะเจาะจง
- ห้ามข้ามข้อมูลใน {{features}} เด็ดขาด — ให้ถือว่าเป็นข้อมูลบังคับที่ต้องพูดถึง

⚠️ สำคัญมาก - การวิเคราะห์สินค้า:
- ต้องวิเคราะห์ภาพสินค้าอย่างละเอียดเพื่อระบุประเภทสินค้า (อาหาร, เครื่องสำอาง, เครื่องใช้ไฟฟ้า, เสื้อผ้า, ของใช้ในบ้าน, ผลิตภัณฑ์ทำความสะอาด, ฯลฯ)
- ต้องวิเคราะห์ชื่อสินค้าเพื่อเข้าใจจุดเด่นที่แท้จริงของสินค้า
- ต้องสร้างจุดเด่นที่เฉพาะเจาะจงกับสินค้านั้นๆ เท่านั้น
- ห้ามใช้ประโยคตายตัวที่ใช้ได้กับทุกสินค้า เช่น "ใช้งานง่าย", "ทนทาน", "ใช้งานได้จริง", "คุ้มค่า" เว้นแต่สินค้านั้นจริงๆ มีคุณสมบัตินั้น
- ต้องสร้างประโยคที่เฉพาะเจาะจง เช่น:
  * ผงซักผ้า → "ซักสะอาด", "ขจัดคราบ", "กลิ่นหอม"
  * ครีมบำรุง → "บำรุงผิว", "ให้ความชุ่มชื้น", "ดูอ่อนเยาว์"
  * อาหาร → "รสชาติ", "คุณภาพ", "ความสด"
  * เครื่องใช้ไฟฟ้า → "ประหยัดไฟ", "ใช้งานสะดวก", "คุณภาพดี"
  * เสื้อผ้า → "สวมใส่สบาย", "สวยงาม", "ทนทาน"

⚠️ โครงสร้างเวลาบังคับ — แบ่งเป็น 3 ส่วน (Problem → Value → CTA):
ช่วงเวลาใน template นี้ ยึดตามนี้เป็นหลัก: {{timing_structure}}
- PROBLEM: เปิดด้วยปัญหาที่ลูกค้าเจอ หรือความไม่พอใจกับของเดิม เพื่อดึงความสนใจทันที (อยู่ช่องแรก)
- VALUE: แนะนำสินค้า (พูดชื่อสินค้าแค่ครั้งเดียวตรงนี้) และบอกประโยชน์หลัก 1-2 อย่างที่เฉพาะเจาะจงกับสินค้านั้นๆ ต้องพูดถึง spec จริงจาก {{features}} อย่างน้อย 2 ข้อ (อยู่ช่องกลางช่วงที่ยาวที่สุด)
- CTA: จบด้วยคำกระตุ้นให้ซื้อ ในช่วงท้ายสุดของคลิป ห้ามเกินกว่าความยาวรวมตาม {{timing_structure}}

⚠️ กฎชื่อสินค้า (ห้ามพูดซ้ำเด็ดขาด):
- พูดชื่อสินค้าเพียง 1 ครั้งเท่านั้นในทั้งสคริปต์ (เฉพาะในส่วน VALUE เมื่อเริ่มแนะนำสินค้า)
- หลังจากพูดชื่อสินค้าครั้งแรกแล้ว ห้ามพูดชื่อสินค้าซ้ำอีกเด็ดขาด
- ในส่วน PROBLEM และ CTA ห้ามพูดชื่อสินค้าเด็ดขาด
- ห้ามใช้สรรพนามแทนชื่อสินค้า เช่น "ตัวนี้" "เจ้าตัวนี้" "ของตัวนี้" "อันนี้" "มัน" เด็ดขาด — หลังพูดชื่อครั้งแรกแล้ว ให้พูดประโยคต่อไปแบบตรงๆ ไม่ต้องอ้างชื่อหรือประธานซ้ำเลย
- ตัวอย่างที่ถูกต้อง: "เบื่อแล้วของเดิมใช้แล้วไม่เวิร์ก {{product_name}} ช่วยแก้ให้ตรงจุด ใช้แล้วดีจริง กดดูในตะกร้าเลย" (ชื่อสินค้าพูดแค่ครั้งเดียว ต่อด้วยประโยคตรงๆ ไม่ใช้ตัวนี้)
- ตัวอย่างที่ผิด (ห้ามทำ): "เบื่อแล้วของเดิมใช้แล้วไม่เวิร์ก {{product_name}} ตัวนี้คือ {{product_name}} ช่วยแก้ให้ตรงจุด {{product_name}} ใช้แล้วดีจริง" (พูดชื่อซ้ำ 3 ครั้ง + ใช้ตัวนี้ — ห้ามเด็ดขาด)

⚠️ ทับศัพท์ชื่อแบรนด์และคำเฉพาะเป็นภาษาไทย:
- ชื่อแบรนด์/ชื่อสินค้าที่เป็นตัวอักษรโรมัน ต้องทับศัพท์เป็นไทย เช่น Skinshe → สกินชี, Moleculogy → โมเลคิวโลจี้, GLUTA → กลูต้า
- คำเฉพาะทาง: SPF → เอส พี เอฟ, SPF50+ → เอส พี เอฟ ห้าสิบพลัส, PA+++ → พี เอ พลัสสาม
- ตัวเลข/หน่วย: 50g → ห้าสิบกรัม, 30ml → สามสิบมิลลิลิตร
- ห้ามทิ้งตัวอักษรโรมัน/ตัวเลข/เครื่องหมาย (Skinshe, SPF50+, 50g) ไว้ในสคริปต์ — แปลเป็นภาษาไทยพูดหมด
